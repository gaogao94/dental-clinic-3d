# 出图与报价 · 交付样例

三个典型配置（平台 S/M/L）由演示页当前代码直接生成：`node _lead_scratch/gen-samples.mjs`（生成脚本见仓库外 `_lead_scratch/`，
核心调用链 `buildPlan → buildQuote → buildDrawing → toDXF / toSVG`，与页面「出图」按钮完全同源）。

| 文件 | 说明 |
|---|---|
| `*.dxf` | 施工图底图：DXF R2007（AC1021，UTF-8），单位 **mm**，13 个中文图层（A-外墙/内墙/门/家具/文字/标注、M-给水/排水、E-强电/弱电、G-气、A-图例、TK-图框）；含 平面布置图 + 机电点位图 + 工程量与估价表 三页（表页 2 页时续页） |
| `*.svg` | 同一张图的 SVG（浏览器可直接看，打印 A2 横向） |
| `*-plan.png` / `*-mep.png` / `*-boq.png` | 图页预览（2400×1720 PNG，来自同一份 SVG） |
| `*.csv` | 报价明细（UTF-8 BOM，Excel 直接打开；分组/明细/合计/工时） |
| `*.quote.json` | 估价与工时汇总（config / totals / labor / groups） |
| `index.json` | 三个样例的指标汇总 |

| 配置 | 面积 | 椅位 | 房间 | 估价 | 单方 | 每椅 | 工时 | 工期 |
|---|---|---|---|---|---|---|---|---|
| S · 社区家庭店 · 洁净蓝白 | 90㎡ | 2 | 7 | ¥645,578 | 7,173 元/㎡ | 32.3 万 | 80.2 人天 | 24 天 |
| M · 种植旗舰店 + 影像/咨询 · 暖奶油 | 150㎡ | 4 | 11 | ¥1,882,299 | 12,549 元/㎡ | 47.1 万 | 133.0 人天 | 37 天 |
| L · 美学体验店 + 咨询/咖啡/儿童 · 疗愈木 | 240㎡ | 6 | 14 | ¥2,114,340 | 8,810 元/㎡ | 35.2 万 | 182.2 人天 | 51 天 |

口径：方案阶段估算（含税、±8% 区间；工期为净施工工期，不含设备采购与报建审批）；出图为平面布置图/机电点位图，
可作 CAD 二次设计底图，**不是结构/节点施工图**。单价与工效见 `dental/server/public/demo/js/price-book.js`，商务可直接改数。
