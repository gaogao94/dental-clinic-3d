# 口腔诊所平台 · 3D 演示页（源码副本）

同一个「诊所平台」，通过平台档位、门店类型、风格与选装模块，配置出不同类型的牙科诊所——像汽车平台衍生车型一样。

> **在线体验：<https://dma.automed.cn/demo/index.html>**
>
> 本目录是演示页的**源码副本**，用于公开阅读与本地运行。非本机访问时，`index.html` 会自动跳转到上面的正式演示地址；正式演示由自托管服务器提供模型（浏览器不直接访问对象存储）。

## 能做什么

- **平台 S / M / L**：90㎡·2 椅 / 150㎡·4 椅 / 240㎡·6 椅——面积、诊室、椅位、模块槽位作为「硬点带宽」
- **5 类门店**：社区家庭店 / 儿童诊疗店 / 正畸中心 / 种植旗舰店 / 美学体验店
- **5 种风格**：洁净蓝白 / 儿童糖果 / 极简黑白 / 疗愈木 / 暖奶油
- **选装模块**：影像室 / 技工室 / 儿童区 / 咨询室 / 咖啡吧 / 消毒升级，超槽位自动禁用
- **3D 交互**：旋转、缩放、平移；视角飞入；点选物件查看名称与分类
- **平台化视图**：硬点（水 / 电 / 气 / 排 / 网）、平台件 / 差异件描边与计数、平台矩阵户型图、指标面板
- **出图与报价**：当前配置 → 平面布置图 / 机电点位图 / 工程量与估价表；DXF / SVG / 报价 CSV / 打印

## 本地运行

需要 Node 18+；three.js 已本地化，无需 `npm install`。

```bash
node demo/serve.mjs            # 在仓库根目录执行
# → http://127.0.0.1:<port>/demo/index.html
```

**模型不在本仓库**（351 件交付 GLB + 152 件演示 LOD + 9 件补充件，合计约 4.2 GB）。本地运行前需要把模型放回：

- `demo/lod-models/<id>/model.glb` — 演示默认使用的 152 件轻量模型（建议先只放这些）
- `demo/extra/models/<id>/model.glb` — 9 件场景补充件

缺少模型时场景会停在加载状态；线上演示不需要这一步。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html` | 入口（含跳转守卫） |
| `js/config.js` | 平台、门店类型、风格、模块、差异件白名单 |
| `js/plan.js` | 房间与家具布局算法 |
| `js/scene.js` | three.js 场景、壳体、灯光、相机 |
| `js/assets.js` | 模型加载、LOD 回退、克隆复用 |
| `js/cad.js` | A2 图框、图层、墙门家具、点位、标注 → DXF / SVG |
| `js/quote.js` · `js/price-book.js` | 工程量、五组造价、工时工期；单价与工效数据 |
| `js/footprint.js` | 119 件资产的实测平面占位 |
| `data/asset-tuning.json` | 尺寸、朝向与落地基准 |
| `extra/` | 9 件补充件的清单与生成脚本 |

口径：方案估算（含税、±8% 区间；工期为净施工工期）；出图是方案阶段平面布置图 + 机电点位图，可作 CAD 二次设计底图，不是结构 / 节点施工图。
